# Climate Fund Watch — Web (Phase B)

Public narrative site for Climate Fund Watch.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm start
```

## Pages

- `/` — Landing
- `/about` — Product definition, audiences, principles
- `/problem-solution` — Problem table, theory of change, modules
- `/get-involved` — Partnership paths

## Stack

Next.js (App Router) · TypeScript · Tailwind CSS v4
